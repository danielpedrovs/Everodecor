EveroDecor - Painting & Decorating Website
Description

EveroDecor is a responsive, modern website showcasing painting and decorating services.
It includes sections for services offered, gallery, testimonials, and contact info.
The design is mobile-friendly and features smooth scrolling, a hamburger menu for mobile, and interactive social links.

Installation
Desktop

Clone the repository:

git clone https://github.com/yourusername/everodecor.git


Navigate to the folder:

cd everodecor


Open index.html in your web browser.

Mobile (Install on Home Screen)

Open the website in your mobile browser (Safari for iOS, Chrome for Android).

iOS (Safari):

Tap the Share icon (square with an arrow pointing up).

Scroll and select Add to Home Screen.

Tap Add.

Android (Chrome):

Tap the menu (three dots) in the top-right corner.

Select Add to Home Screen.

Follow the prompt to add the icon.

Now the website behaves like an app and can be accessed directly from the home screen.

Usage

Navigate the menu to scroll to different sections: Services, Gallery, Contact.

Click social icons to visit external platforms (TaskRabbit, Instagram, MyBuilder, Airtasker, Oscar).

The image gallery and testimonial carousels are fully interactive.

Click Call-to-Action buttons for free quotes or to contact via email.

Works smoothly on desktop and mobile devices.

Features

Responsive design using Tailwind CSS.

Hamburger menu for mobile screens.

Smooth scrolling to sections via navigation links.

Interactive image gallery with carousel navigation.

Testimonials carousel with automatic and manual scrolling.

Call-to-action buttons for free quote and contact.

Clickable social icons linking to external platforms.

Mobile home screen support for quick access like an app.
